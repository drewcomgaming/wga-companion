# Icons

`slay_mono.tga`, `loot_mono.tga`, `object_mono.tga` and `node.tga` come from
[pfQuest](https://github.com/shagu/pfQuest) by Eric Mauser (Shagu), via Questie's `Icons`
folder, where they are listed as MIT licensed. See `MIT.txt` in this folder.

`arrow.tga`, `ring.tga`, `halo.tga` and `logo.tga` were drawn for WGA Companion and is GPL-3.0 like the rest of the addon.

Every other texture WGA Companion uses is built into the game client.
